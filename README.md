这是我第一个自己独立完成的程序，回想起4年前，在恍惚，梦游感充斥的夏日，我进入了一所校园，告别了按部就班的职高生活。如一部分的大专生一样，我缺少了对时间的敬畏，与对未来的规划，整日将时间浪费在宿舍，只有一个目标就是不挂科就行，在室友的帮助下我顺利的完成了自己的学业，这不是件很值得骄傲的事，但室友他们都是很不错的人，认识他们不后悔。日子就在每日的糊弄中度过了，直到毕业，我们畅想未来，意气风发，认为找工作不就是手到擒来的事，现实却不得不让我们学会了低头。

大三，我们找不到实习，只能各种投递简历，室友p进了工厂，一个画图岗位，但要接受1年没工资，过年才有几千的补贴金，第二年开始才微薄的收入.室友c干过客服然后电商后面是机器人部署，貌似开始越来越好了，但愿吧。室友d先是进了亲戚的工厂过渡，后来他成功的进入一个低代码开发岗位，应该过的也不错。室友w去干了客服，后来在家待业了。我则因为身体不好，跟这个社会暂且脱节并成了家里蹲，在父母的安排的相亲下，21岁的大概是年少气盛吧，面对相亲对象的羞辱，我忍耐不住，离家出走了，在一个陌生的城市，在同学的帮助下打起了电子螺丝，收入不高，但在自己的节俭下，还是稍微能活下去。

那时我的一天大概就是在上班下班中度过，薪水3500的情况下，加上经常的焦虑让我变得格外节俭，我会在晚上10点前打开某买菜平台，1.5元就能买到一斤青菜，7元就能买到一块鸡胸肉，不过够了（剩下一部分睡醒写）。
