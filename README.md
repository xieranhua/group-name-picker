# 如何使用
```mermaid
graph TD;
    A[有名单]-->B[导入名单]-->C[点击按钮点名];
    D[无名单]-->E[打开群聊，在输入框键入群聊名]-->F[选择保存地址，键入文件名]-->G[确保群聊显示在聊天窗口中间，点击获取按钮]-->H[点击生成，文件就生成了]-->I[导入名单]-->C;
```
